# บัตรทดลองและติดตามหนึ่งประเด็น

ใช้เมื่อครูต้องการแผนทดลอง/บันทึก ไม่แทรกเป็นแบบฟอร์มใน Coach ทุกครั้ง ตัวอย่างทั้งหมดให้ครูกรอกจากสิ่งเกิดจริง ไม่ใส่ชื่อเด็กหรือข้อมูลอ่อนไหว

**จังหวะ:** ก่อนเริ่ม / ระหว่างเรียน / เมื่อติดขัด / หลังเรียน

**ประเด็นพัฒนา 1 เรื่องและเป้าหมายการเรียนรู้:**

**สิ่งที่จะลองทำหนึ่งอย่าง:**

**สิ่งที่ควรเห็นถ้าการปรับช่วยได้:**

**สัญญาณที่ชวนตรวจเพิ่ม โดยยังไม่ตัดสินสาเหตุ:**

**หลักฐานที่มีจริง:** ชิ้นงาน/เหตุผล/ข้อเสนอ/การตัดสินใจที่เปลี่ยน/ข้อมูลการเข้าถึง ระบุสิ่งที่มีและสิ่งยังไม่มี

**หลังลอง:** สิ่งที่พบ → คำอธิบายที่เป็นไปได้ → ก้าวถัดไปที่ครูเลือก

เมื่อเกี่ยวข้อง แยก “ความเข้าใจวิชา” ออกจาก “ความพร้อมเรียน” ให้ทางเลือกไม่เปิดเผยความรู้สึก ไม่มีคะแนนสุขภาพจิตหรือคะแนนรวมความเสมอภาค

ถ้าขอเทียบระดับ ใช้ R…-L… พร้อมหลักฐานสนับสนุน ข้อขัดแย้งและขอบเขต ห้ามใช้บัตรที่ยังไม่กรอกเป็นหลักฐานว่าผลสำเร็จเกิดแล้ว
