# Rubric V4 ระดับพัฒนาการรายมิติ

สรุปเรียบเรียงใหม่จากเอกสารผู้ใช้ `001.Rubric  Unicef V4.docx` ตาราง Rubric และส่วนขยายรายมิติ ไม่ใช่สำเนาฉบับเต็มหรือเครื่องมือรับรองจากหน่วยงาน ดู `framework-sources.md` สำหรับที่มาและข้อจำกัด

## วิธีใช้หลักฐาน

- ใช้เพื่อชี้ก้าวพัฒนา 1–2 มิติ ไม่บังคับยกระดับทุกมิติในคาบเดียว ไม่แปลงระดับเป็นคะแนนรวม/ร้อยละ
- แผนบอกเจตนาได้เท่านั้น หากครูขอระดับ ให้มีหลักฐานการสอนจริงที่ตรง descriptor และระบุทั้งสิ่งสนับสนุน สิ่งขัดแย้ง และสิ่งยังไม่ทราบ
- ถ้ามีหลักฐานเพียงพอและครูขอ สามารถเทียบระดับรายมิติอย่างมีเงื่อนไขได้ ไม่ปฏิเสธทุกครั้งอัตโนมัติ ระบุว่าเป็นการเทียบกับบทสรุป V4 ของโครงการ ไม่ใช่การรับรองผู้เรียน/ครูหรือ UNICEF
- L4 อาศัยการร่วมออกแบบระบบและการใช้/ปรับต่อเนื่อง ไม่ให้จากการโหวตหรือหมุนบทบาทเพียงครั้งเดียว ข้อมูลที่ครูรายงานยังไม่ใช่การสังเกตโดย Agent
- มิติหนึ่งอาจมีหลักฐานปะปนหลายระดับ เลือกอธิบายช่องว่างแทนบังคับฟันธง และไม่ขยายผลไปมิติที่ไม่มีข้อมูล
- ตัวอย่างเสียงผู้เรียนเป็นตัวช่วยตีความ ไม่ใช่ประโยคที่เด็กต้องพูดหรือหลักฐานจริงโดยอัตโนมัติ ไม่แต่งคำพูดเติมเพื่อให้ครบ
- การมีเสียงรวมการเขียน การชี้ภาพ หรือการสื่อสารผ่านคู่ ไม่บังคับพูดต่อหน้าชั้น เปิดเผยอารมณ์ หรือระบุตัวตน/เพศ

## R1 Role & Voice — บทบาทและเสียง

| รหัส | ระดับ | ลักษณะที่ใช้เทียบ |
|---|---|---|
| R1-L1 | Symbolic | รับหน้าที่ตามชื่อหรือคำสั่ง แต่ยังไม่เข้าใจคุณค่าหรือไม่มีส่วนคิด |
| R1-L2 | Functional | ทำหน้าที่พื้นฐานได้ แต่งานและความรับผิดชอบยังแยกกัน |
| R1-L3 | Reflective | ใช้บทบาทพร้อมสะท้อนว่าใครขาดโอกาส และปรับการมีส่วนร่วมให้เป็นธรรม |
| R1-L4 | Transformative | ผู้เรียนกับครูร่วมปรับระบบบทบาท ใช้เสียงผู้เรียนและความเป็นเจ้าของร่วมอย่างต่อเนื่อง |

## R2 Agency & Co-Decision — สิทธิและการตัดสินใจร่วม

| รหัส | ระดับ | ลักษณะที่ใช้เทียบ |
|---|---|---|
| R2-L1 | Symbolic | ครูกำหนดผลตัดสินใจ สิทธิของผู้เรียนยังไม่มีผลจริง |
| R2-L2 | Functional | ผู้เรียนเลือกหรือโหวตได้บางเรื่อง แต่ผู้เสนอและโอกาสยังจำกัด |
| R2-L3 | Reflective | ผู้เรียนตรวจความเป็นธรรมของการตัดสินใจ และมีช่องทางให้หลายเสียงมีผลจริง |
| R2-L4 | Transformative | ครูและผู้เรียนร่วมสร้างกติกาตัดสินใจที่เปิดกว้าง ใช้และปรับระบบนั้นร่วมกัน |

## R3 Reality-Based Data Use — การใช้ข้อมูลที่สะท้อนความเป็นจริง

| รหัส | ระดับ | ลักษณะที่ใช้เทียบ |
|---|---|---|
| R3-L1 | Symbolic | ตัดสินจากภาพจำหรือข้อมูลผิวเผิน โดยยังไม่เห็นคุณภาพและบริบทผู้เรียน |
| R3-L2 | Functional | เก็บคะแนนหรือชิ้นงานจริง แต่เน้นบันทึกหรือภาพรวมมากกว่านำไปปรับโอกาส |
| R3-L3 | Reflective | ใช้หลักฐานเชิงปริมาณและคุณภาพตรวจว่าใครเข้าถึงหรือขาดโอกาส แล้วสะท้อนความเป็นธรรม |
| R3-L4 | Transformative | ครูกับผู้เรียนร่วมตีความหลักฐานและใช้เปลี่ยนกระบวนการเรียนรู้ให้เป็นธรรมอย่างต่อเนื่อง |

## R4 Real-Life Relevance — ความหมายต่อชีวิตจริง

| รหัส | ระดับ | ลักษณะที่ใช้เทียบ |
|---|---|---|
| R4-L1 | Symbolic | มีตัวอย่างชีวิตหรืออาชีพ แต่ผู้เรียนยังไม่เห็นความหมายกับตน |
| R4-L2 | Functional | ผู้เรียนอธิบายความเชื่อมโยงพื้นฐานได้ แต่ยังไม่เห็นคุณค่าต่อชีวิตตนชัด |
| R4-L3 | Reflective | ผู้เรียนเชื่อมบทเรียนกับชีวิตหรืออนาคตตน และสะท้อนโอกาสที่ไม่ถูกจำกัดด้วยภาพจำเพศ |
| R4-L4 | Transformative | ผู้เรียนใช้ความรู้ร่วมออกแบบแนวทางเพื่อชีวิต อาชีพ ชุมชน หรือความยั่งยืน พร้อมเห็นคุณค่าบทบาทที่หลากหลาย |

## R5 Discussion & Reflection — คุณภาพการแลกเปลี่ยนและสะท้อนคิด

| รหัส | ระดับ | ลักษณะที่ใช้เทียบ |
|---|---|---|
| R5-L1 | Symbolic | ถามตอบหรือสะท้อนเพื่อจบขั้นตอน ยังไม่แสดงการสร้างความหมาย |
| R5-L2 | Functional | เล่าสิ่งที่ทำหรืออธิบายพื้นฐานได้ แต่ยังแลกเปลี่ยนและเชื่อมมุมมองจำกัด |
| R5-L3 | Reflective | ใช้เหตุผล ฟังและต่อยอดความคิด เชื่อมความต่างและสะท้อนความเป็นธรรม |
| R5-L4 | Transformative | ครูและผู้เรียนใช้สิ่งที่สะท้อนร่วมกันเป็นฐานตัดสินใจและปรับระบบการเรียนรู้อย่างต่อเนื่อง |

## R6 Gender-Inclusive Access — การเข้าถึงโอกาสและการก้าวข้ามภาพจำทางเพศ

| รหัส | ระดับ | ลักษณะที่ใช้เทียบ |
|---|---|---|
| R6-L1 | Symbolic | ความเคยชินหรือภาพจำเพศยังจำกัดบทบาทและโอกาสโดยไม่ได้ตรวจสอบ |
| R6-L2 | Functional | บางคนได้ลองข้ามภาพจำตามสถานการณ์ แต่ยังไม่ได้ออกแบบและติดตามให้ทั่วถึง |
| R6-L3 | Reflective | ครูออกแบบโอกาสอย่างตั้งใจ ผู้เรียนเริ่มสะท้อนความเป็นธรรมและการยอมรับความต่าง |
| R6-L4 | Transformative | ครูและผู้เรียนร่วมปรับระบบ ติดตามโอกาสและการยอมรับอย่างต่อเนื่อง จนการเข้าถึงไม่ขึ้นกับภาพจำเพศ |

## ความสัมพันธ์ที่ใช้เลือกคำถามหรือการปรับ

นี่เป็นแนววิเคราะห์จากต้นฉบับ ไม่ใช่ข้อสรุปเชิงสาเหตุที่พิสูจน์แล้ว เลือกความสัมพันธ์ที่มีหลักฐานรองรับหนึ่งคู่ ไม่เล่าทั้งเครือข่ายทุกครั้ง

| คู่/กลุ่ม | ตรวจประเด็นใด |
|---|---|
| R1 ↔ R2 | ได้หน้าที่แล้ว ข้อเสนอมีผลต่อการตัดสินใจจริงหรือยัง |
| R2 ↔ R3 | การเลือกหรือโหวตใช้ข้อมูลที่นับหลายเสียง หรือใช้เพียงคะแนน/คนกลุ่มเดิม |
| R3 ↔ R4 | ข้อมูลจากผู้เรียนช่วยให้โจทย์มีความหมายกับชีวิตของเขาหรือยัง |
| R4 ↔ R5 | มีตัวอย่างชีวิตจริงแล้ว ผู้เรียนได้สร้างความหมายของตนผ่านการแลกเปลี่ยนหรือยัง |
| R3 ↔ R6 | ภาพรวมซ่อนช่องว่างโอกาสหรือไม่ ใช้ข้อมูลที่ครูให้โดยไม่เดาเพศหรือเผยกลุ่มย่อยระบุตัวบุคคล |
| R6 ↔ R1 และมิติอื่น | การข้ามภาพจำเป็นโอกาสเฉพาะกิจหรือมีระบบที่ทุกคนเข้าถึง |
| R5 ↔ ทุกมิติ | สิ่งที่สะท้อนนำไปเปลี่ยนการตัดสินใจ/กิจกรรมจริงหรือจบแค่เล่า |

## ตัวอย่างสังเคราะห์สำหรับเทียบความลึก

- R1–R2: สมาชิกผลัดกันจดแต่คนเดิมเลือกวิธีทดลองทุกครั้ง → มีการกระจายหน้าที่ แต่สิทธิยังไม่ชัด ชวนตรวจการตัดสินใจ ไม่เสนอหมุนหน้าที่อย่างเดียว
- R3–R6: คะแนนรวมดี แต่ข้อมูลที่ครูให้บอกว่าบางกลุ่มไม่ได้ลองอุปกรณ์ → ตรวจโอกาสและเสียงควบคู่ชิ้นงาน ไม่อนุมานตัวตนจากชื่อ
- R5: เขียนว่าสนุกเป็นข้อมูลความรู้สึกที่รับฟังได้ แต่ยังไม่แสดงเหตุผล/สิ่งที่เรียนรู้/ก้าวถัดไป ห้ามตีความว่าเด็กไม่มีความคิด
- R2-L3: มีบันทึกหลายคาบว่าผู้เรียนเสนอเหตุผลหลายช่องทางและช่วยตรวจว่าคำตัดสินนับใครบ้าง แต่ยังไม่มีระบบที่ร่วมออกแบบและใช้ต่อเนื่อง → อาจเทียบเชิงเงื่อนไขกับ L3 เฉพาะ R2 ถ้าครูขอ ไม่ยกทั้งห้องเป็น L4
