# Rubric V4 เลนส์หกมิติ

แหล่งหลักของ RC2 คือ Rubric V4 ที่ผู้ใช้ส่ง ดู framework-sources.md และ rubric-v4-levels.md สำหรับรายละเอียด 24 ช่องและความสัมพันธ์ ไม่ใช่เครื่องมือรับรองจากหน่วยงาน

1. R1 Role & Voice — บทบาทที่มีความหมายและเสียงที่มีคุณค่า ไม่ตรวจเพียงมีหน้าที่ครบ
2. R2 Agency & Co-Decision — ทางเลือกและข้อเสนอมีผลจริงต่อการตัดสินใจ ไม่ตรวจเพียงมีโหวต
3. R3 Reality-Based Data Use — ใช้ข้อมูลเชิงปริมาณและคุณภาพเพื่อเห็นและปรับโอกาส ไม่ตรวจเพียงมีคะแนน/ค่าเฉลี่ย
4. R4 Real-Life Relevance — ผู้เรียนสร้างความหมายกับชีวิต อาชีพและชุมชน ไม่ตรวจเพียงยกตัวอย่างชีวิตจริง
5. R5 Discussion & Reflection — มีเหตุผล ฟัง/ต่อยอดมุมมอง และนำไปปรับการเรียนรู้ ไม่ตรวจเพียงทำ exit ticket หรือบอกสนุก
6. R6 Gender-Inclusive Access — โอกาสและการยอมรับที่ก้าวข้ามภาพจำเพศอย่างตั้งใจและต่อเนื่อง ไม่ตรวจเพียงสลับคนครั้งเดียว

L1 Symbolic → L2 Functional → L3 Reflective → L4 Transformative เป็นเส้นทางพัฒนาในแต่ละมิติ ไม่มีคะแนนรวมที่ระบบกำหนดเอง ตรวจแผนใช้ แสดงในแผน / ยังไม่ชัด / ต้องสังเกตเมื่อสอนจริง ถ้าครูขอเทียบระดับจากหลักฐานจริงให้ใช้รายละเอียดรายมิติพร้อมข้อจำกัด ไม่ให้ระดับที่ไม่มีหลักฐานและไม่ปฏิเสธการเทียบอย่างมีเงื่อนไขเมื่อหลักฐานเพียงพอ

Compass 6 จุดเป็นเลนส์ออกแบบเสริม Checklist V8 เป็นรายการลงมือ 4 เสา ไม่ใช่ชื่ออื่นของ Rubric นี้ ไม่มีการรับรองจากชื่อไฟล์หรือโลโก้ต้นฉบับ
