# 5E เป็นทางเลือกในการออกแบบและปรับแผน

พิจารณาใช้ BSCS 5E กับงานสืบเสาะที่เหมาะสม ครูเลือกใช้รูปแบบอื่นหรือไม่ใช้5Eได้ โดยรักษาวัตถุประสงค์ เวลาและทรัพยากร ไม่บังคับรูปแบบสากลเพียงแบบเดียว

| ขั้น | หน้าที่ของการเรียนรู้ |
|---|---|
| Engage — สร้างความสนใจ | ตั้งประเด็นที่โยงความรู้เดิมและเปิดให้เห็นความคิดเริ่มต้น |
| Explore — สำรวจ | ผู้เรียนศึกษาหลักฐาน/ลงมือค้นรูปแบบก่อนรับข้อสรุปสำเร็จ |
| Explain — อธิบาย | ผู้เรียนอธิบายจากสิ่งที่สำรวจ ครูช่วยเชื่อมแนวคิดและตรวจความถูกต้อง |
| Elaborate — ขยายความรู้ | ลองใช้ความเข้าใจในโจทย์หรือบริบทใหม่ที่ต้องถ่ายโอนความคิด |
| Evaluate — ประเมิน | ให้ผู้เรียนและครูดูหลักฐานว่าเข้าใจตามเป้าหมายเพียงใด |

แหล่งหลัก: BSCS, *The BSCS 5E Instructional Model: Origins and Effectiveness* (2006), ตาราง1และการใช้งานเป็นลำดับการเรียนรู้ ([รายงาน](https://bscs.org/wp-content/uploads/2022/01/bscs_5e_full_report-1.pdf), [หน้าต้นทาง](https://bscs.org/reports/the-bscs-5e-instructional-model-origins-and-effectiveness/)). ข้อความข้างต้นเป็นบทสรุปที่เขียนขึ้น ไม่แจกสำเนารายงานหรืออ้างการรับรองผลิตภัณฑ์

## กติกาของผลิตภัณฑ์เมื่อเลือกใช้

- เลือกเพราะช่วยเป้าหมายและบริบท ไม่ใช้เพียงตั้งชื่อหัวข้อให้ดูครบ
- 5Eจัดโครงลำดับการเรียนรู้ ไม่ใช่HIPห้าแนวหรือRubricห้ามิติ ยังเลือกHIPหลัก1–2แนวที่เหมาะกับช่องว่าง
- อาจจัดต่อเนื่องหลายคาบตามเนื้อหา แบ่งเวลาที่ทำจริงในแต่ละคาบให้ชัด; ไม่จำเป็นต้องอ้างว่าคาบ10–20นาทีทำครบวงจรอย่างมีคุณภาพ
- ถ้าครูขอใช้5E ให้ระบุสิ่งที่ผู้เรียนทำและหลักฐานในแต่ละขั้น; Explainต้องมีการอธิบายของผู้เรียน ไม่กลายเป็นครูบรรยายอย่างเดียว; Elaborateต้องมีการใช้ความรู้กับโจทย์ใหม่ ไม่เรียกการทำซ้ำเดิมว่าถ่ายโอน
- ประเมินระหว่างกิจกรรมได้ด้วย ไม่รอEvaluateท้ายลำดับอย่างเดียว และแยกการประเมินผู้เรียนจากQAตรวจชิ้นงานAgent
- ถ้าครูมีแผนรูปแบบอื่น ให้ปรับสาระ/Equity/HIPในรูปแบบเดิมก่อน เว้นแต่ครูขอเปลี่ยน ถ้าครูบอกไม่ใช้5E ไม่เสนอซ้ำโดยไม่จำเป็น
- ในคาบสั้น เลือกกิจกรรมที่เหมาะหรืออธิบายว่าเป็นช่วงหนึ่งของหน่วย5E ไม่เพิ่มเวลาหรือชิ้นงานเพื่อให้ครบชื่อขั้น

การตรวจใช้เกณฑ์ว่าเหมาะกับโจทย์และทำได้จริง ไม่ใช่เกณฑ์ว่าแผนที่ไม่มี5Eไม่ผ่าน
