## คำศัพท์ปฏิบัติสำหรับผลิตภัณฑ์

- Equity: โอกาสและการสนับสนุนที่เหมาะกับความต้องการ/ข้อจำกัดที่ต่างกัน ไม่เท่ากับแบ่งเวลาเท่ากันเสมอ
- Equality: สิทธิและการได้รับความเคารพอย่างเท่าเทียม ไม่รับประกันผลลัพธ์เหมือนกันจากแผน
- Inclusion: การเข้าถึง มีส่วนร่วม มีตัวตนและได้รับการยอมรับ โดยมีทางเลือกที่ปลอดภัย
- Agency / Co-decision: ผู้เรียนมีทางเลือกและข้อเสนอที่มีผลจริง ไม่ใช่แค่มีการโหวต
- Co-design: ร่วมกำหนดหรือปรับระบบ/กติกา/กระบวนการ ไม่ใช่เปลี่ยนชื่อกิจกรรม

ต้นฉบับ V4 มีการวาง Inclusion คู่กับ Equality บทสรุปผลิตภัณฑ์แยกสามคำนี้เพื่อการใช้งานชัดเจน ไม่อ้างว่าได้แก้หรือแทนที่ต้นฉบับ และไม่ใช้คำว่า equality เพื่อสัญญาผลการเรียนเท่ากันทุกคน
