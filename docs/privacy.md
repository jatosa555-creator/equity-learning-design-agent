# Privacy — Equity Learning Design Agent

Effective: 23 October 2026. Publisher: **CHANON PHAJUNDA**.

## Scope

This project supplies teaching-workflow Skills and a public, read-only knowledge MCP. Its curated snapshot contains owner-authorized summaries of Rubric V4, Checklist V8, Mini-Box, Compass, HIP and Formative 3D. It contains no individual teacher or student records. It has no live Google Drive connection, user database, persistent conversation memory or monitoring service.

## Information processed

The MCP receives the generic search topic or item IDs that your AI client sends, together with ordinary network request information handled by the hosting provider, such as IP address and request time. Use teaching topics only. Do not submit names, student records, photographs, sensitive experiences, school identifiers, passwords or other personal information. The service does not need that information to retrieve public reference material.

Lesson text entered into ChatGPT/Codex is processed by that product under its own terms and privacy settings. The MCP does not need or request a complete lesson plan; the Skill instructs the assistant to send only generic retrieval topics. Model behavior is not a technical guarantee, so review tool-call inputs when available.

## Purpose, recipients and retention

Requests are used only to search or read the public teaching library. The application does not create accounts, store submitted lessons or queries in an application database, sell data, or run analytics trackers. Netlify hosts the endpoint and may process operational/security logs under its platform policies and the publisher's hosting settings. GitHub hosts project documents and support issues. Your AI-client provider processes conversations and returned references under its own policy. Infrastructure logging and retention are separate from this application's lack of query storage; this project does not promise a universal deletion period across those services.

## Your controls and support

Use generic topics, redact identifying information, stop using or disconnect the MCP, and manage conversation retention in your AI client. Public GitHub issues are visible to everyone: never include personal records or credentials there. For a privacy or deletion concern, open an issue describing the concern without the affected personal data and request a safe follow-up channel from the publisher. Do not post the sensitive material itself. Infrastructure data requests will be handled through the relevant provider's available controls.

Support: https://github.com/jatosa555-creator/equity-learning-design-agent/issues

This policy must be updated before adding private Drive access, accounts, uploads, stored learner information or analytics.
