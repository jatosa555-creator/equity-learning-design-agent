# สาธิตคณิตศาสตร์: 1/2 เท่ากับ 2/4 เพราะอะไร

กรณีสังเคราะห์สำหรับอบรม ผู้พัฒนาจัดทำและตรวจตัวเลข ไม่ใช่ผลทดลองกับครูหรือผู้เรียนจริง

คำสั่งสำหรับDesign: “ออกแบบคณิต ป.4 30นาที ใช้เฉพาะกระดาษดินสอ เป้าหมายอธิบาย1/2=2/4 ขอแผน ใบงานสั้นและexit ticket ตรวจเวลารวมและความครบก่อนส่ง”

คำสั่งสำหรับQuick QA→Improve: เริ่มจากแผนเดิมครูเฉลย10นาที นักเรียนทำโจทย์15นาที ครูตรวจ5นาที ให้ตรวจแล้วขอปรับโดยคงเป้าหมายและเวลาเดิม

| เดิม | ปรับ | หลักฐานที่จะเก็บ |
|---|---|---|
| ครูเฉลยก่อน | นักเรียนสร้างภาพและเหตุผลก่อนสรุป | ภาพที่แบ่งส่วนเท่ากันและข้อความเหตุผล |
| ตรวจคำตอบอย่างเดียว | ตรวจทั้งปริมาณของส่วนทั้งหมดและส่วนที่เลือก | เห็นผู้ที่ตอบถูกแต่ใช้เหตุผลคลาดเคลื่อน |
| คนเดิมเป็นผู้ตอบ | คิดเดี่ยว ทำคู่สลับหน้าที่ และexit ticketเดี่ยว | ผลงานรายคนและการได้อธิบาย |

HIPหลัก2แนว: งานคู่ที่มีบทบาท และการประเมินระหว่างเรียน สมมติว่านักเรียนรู้จักเศษส่วนเบื้องต้น หากยังไม่รู้ให้ครูปรับโจทย์ก่อนใช้

| นาที | กิจกรรม |
|---|---|
| 0–4 | ครูวาดสี่เหลี่ยมขนาดเท่ากัน2รูปบนกระดาษ แบ่งครึ่งกับแบ่งสี่ส่วน ให้นักเรียนคาดการณ์ว่าระบาย1/2กับ2/4แล้วปริมาณเท่ากันหรือไม่ |
| 4–10 | นักเรียนแต่ละคนวาดรูปขนาดเท่ากัน2รูป แบ่งเป็นส่วนเท่าๆกันและระบายตามเศษส่วน |
| 10–20 | ทำใบงานเป็นคู่ คนหนึ่งชี้หลักฐานอีกคนตรวจเหตุผล สลับหน้าที่หลัง5นาที แต่ละคนต้องมีภาพ/คำอธิบายของตน |
| 20–26 | แลกคำอธิบายโดยส่งกระดาษให้เพื่อนอ่านหรือพูดพร้อมชี้ภาพ ครูสรุปว่าปริมาณเดิมไม่เปลี่ยนเมื่อแบ่งทุกส่วนให้เล็กลงเท่ากัน |
| 26–30 | Exit ticketรายบุคคล |

## ใบงานที่คัด/พิมพ์แจกได้

ไม่ต้องระบุชื่อในงานสาธิต

1. วาดรูปขนาดเท่ากัน2รูป รูปแรกแบ่ง2ส่วนเท่ากันระบาย1ส่วน รูปสองแบ่ง4ส่วนเท่ากันระบาย2ส่วน
2. เติมเครื่องหมาย: `1/2 __ 2/4` อธิบายโดยชี้พื้นที่ที่ระบาย ไม่ใช้แค่การดูว่าตัวเลขใดใหญ่กว่า
3. ถ้ารูปแบ่ง4ส่วนที่ขนาดไม่เท่ากัน ระบาย2ส่วน จะสรุปว่าเป็น2/4ได้ทันทีหรือไม่ เพราะอะไร

## Exit ticketและแนวตรวจ

- เติม`1/2 = __/4` และวาด/เขียนเหตุผล: คำตอบ2 ต้องแสดงว่าปริมาณที่เลือกเท่ากันเมื่อส่วนทั้งหมดมีขนาดเท่ากัน
- “2/4มากกว่า1/2เพราะ2มากกว่า1” ถูกหรือไม่: ไม่ถูก การเปรียบเทียบตัวเศษลำพังไม่บอกค่าของเศษส่วน
- เลือกตอบด้วยภาพ ข้อความ หรือพูดพร้อมชี้ภาพให้ครูฟัง โดยยังต้องแสดงเหตุผลเดียวกัน

ครูดูส่วนที่ยังสับสน เช่นส่วนไม่เท่ากัน หรือภาพทั้งสองมีส่วนทั้งหมดต่างขนาด เพื่อวางแผนช่วยครั้งหน้า ไม่จัดเด็กเป็นเก่ง/อ่อนถาวร

ตรวจต้นแบบ: 4+6+10+6+4=30นาที ใช้กระดาษแสดงงานด้วย ไม่ต้องมีกระดานหรือโปรเจกเตอร์ มีแผน ใบงานและexit ticketครบ ความเข้าใจ/การมีส่วนร่วมจริงต้องเก็บหลักฐานหลังสอน
