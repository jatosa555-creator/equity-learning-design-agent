# สาธิตวิทยาศาสตร์: จากแผนที่บางคนได้แต่ดู สู่แผนทดลองร่วมกัน

เป็นกรณีสังเคราะห์สำหรับฝึกใช้ ไม่ใช่ชิ้นงานครูหรือผลลัพธ์ห้องเรียนจริง ตัวอย่างนี้ผู้พัฒนาคัดและเรียบเรียงเพื่อตรวจความเป็นไปได้ ไม่ใช่ผลโมเดลที่อ้างว่าทดสอบแล้ว

## ข้อความเริ่ม Coach

“ขอปรึกษา เด็กบางคนได้แต่ดูเพื่อนทดลองเครื่องบินกระดาษ ฉันอยากให้มีโอกาสลงมือและอธิบาย โดยไม่แบ่งตามเพศหรือความเก่ง”

ผู้สาธิตตรวจว่า Coach ชวนคิดเพียงประเด็นเดียว ไม่ให้คะแนนหรือรีบเขียนแผนเต็ม เมื่อครูตอบว่าเด็กเลือกบทบาทเองให้ใช้ข้อมูลนั้นต่อ ไม่ถามซ้ำ

## ข้อความเปลี่ยนเป็น Quick QA

“ช่วยตรวจแผน ป.5 เวลา40นาที เป้าหมายอธิบายผลของรูปปีกต่อระยะบิน ใช้กระดาษ ดินสอ ไม้บรรทัด แผนเดิมครูอธิบาย5นาที คนเดิมพับและปล่อย25นาที เพื่อนดู ตัวแทนรายงาน5นาที ครูสรุป5นาที”

สิ่งที่ควรเห็น: เวลาเดิมรวม40นาทีและมีการทดลองตามเป้าหมาย แต่ข้อความคนเดิมพับ/ปล่อยเป็นหลักฐานว่าโอกาสลงมือกระจุก ยังไม่รู้ความเข้าใจรายคนหรือผลความเสมอภาคจริง

## ข้อความเปลี่ยนเป็น Improve Plan

“ปรับแผนเลย คง40นาทีและอุปกรณ์เดิม ขอการทดลองที่เปรียบเทียบรูปปีกอย่างมีเหตุผล พร้อม exit ticket ตรวจงานก่อนส่งด้วย”

| เดิม | ฉบับปรับ | เหตุผลและหลักฐานที่จะดู |
|---|---|---|
| คนเดิมพับและปล่อย | ทุกคนเสนอแบบ แล้วหมุนหน้าที่4รอบ | ตรวจจำนวนคนที่ได้ปล่อย/วัดและเสนอเหตุผล |
| เพื่อนดู | มีผู้วัด ผู้บันทึก ผู้ตรวจเงื่อนไขที่ทำงานจริง | การตัดสินใจอาศัยตารางผล ไม่ใช่บทบาทชื่อเฉยๆ |
| ตัวแทนคนเดียวตอบ | มีexit ticketรายบุคคล | เห็นคำอธิบายของทุกคนที่ส่งงาน ไม่ใช้ตัวแทนแทนทั้งกลุ่ม |

## แผนฉบับตัวอย่าง 40 นาที

HIPหลัก2แนว: งานกลุ่มที่มีเป้าหมาย/บทบาท และการประเมินระหว่างเรียน

| นาที | กิจกรรม |
|---|---|
| 0–5 | แต่ละคนวาด/เขียนคาดการณ์รูปปีกที่น่าบินไกลและเหตุผล แล้วกลุ่มเลือก2แบบร่วมกัน |
| 5–10 | ทำเครื่องบินA/Bจากกระดาษขนาดเดียวกัน ตกลงจุดเริ่ม วิธีปล่อย และวิธีวัดระยะให้เหมือนกัน บันทึกสมมติฐานเรื่องที่ยังควบคุมไม่ได้ |
| 10–30 | ทดลอง4รอบ รอบละ5นาที ใช้ลำดับA,B,A,B หมุนหน้าที่ผู้ปล่อย ผู้วัด ผู้บันทึก ผู้ตรวจเงื่อนไขทุกครั้ง กลุ่ม4คนจึงมีโอกาสทำแต่ละหน้าที่1ครั้ง |
| 30–35 | กลุ่มเปรียบเทียบผลA/B ชี้ความแปรปรวนและสิ่งที่อาจมีผลนอกจากปีก เลือกสรุปด้วยคำพูด ภาพหรือตาราง |
| 35–40 | ตอบexit ticketรายคน ครูเก็บไปวางแผนครั้งถัดไป |

ถ้ากลุ่มไม่ได้มี4คนให้ครูปรับการหมุนหน้าที่และจำนวนรอบก่อนใช้จริง ไม่อ้างว่าครอบคลุมทุกคนโดยไม่ตรวจเงื่อนไขนี้

ตารางที่นักเรียนคัดลงกระดาษ: `รอบ | แบบปีก | ระยะบิน | เงื่อนไขที่ต่าง/ข้อสังเกต` ไม่สร้างตัวเลขผลทดลองล่วงหน้า

Exit ticket:
1. ในการทดลองครั้งนี้AหรือBมีระยะบินต่างกันอย่างไร ยกตัวเลขที่วัดจริงรองรับ
2. สิ่งใดที่อาจทำให้ผลต่างนอกจากรูปปีก และจะตรวจครั้งต่อไปอย่างไร
3. วันนี้ฉันมีส่วนเสนอเหตุผล/ตัดสินใจ/ลงมือเรื่องใด (ไม่ต้องเขียนชื่อสำหรับการสาธิต)

ทางเลือกเข้าถึง: อธิบายโดยชี้ตาราง วาดลูกศร พูดให้ครูฟัง หรือเขียน; การปรับหน้าที่ตามข้อจำกัดของผู้เรียนต้องยังเปิดสิทธิ์ร่วมตัดสินใจ ไม่สรุปความถนัดจากเพศ

ตรวจต้นแบบ: 5+5+20+5+5=40นาที ใช้วัสดุเดิม มีการเปรียบเทียบและexit ticketตรงเป้าหมาย ส่วนผลการเรียนรู้/การมีส่วนร่วมจริงยังยืนยันไม่ได้ ต้องสังเกตเมื่อสอน

3Dหลังสอน: Decodeตารางผลและคำอธิบายรายคน → Distillว่ายังสับสนการใช้หลักฐานหรือการควบคุมตัวแปรตรงไหน → Designการทดลอง/คำถามครั้งถัดไปหนึ่งจุด
